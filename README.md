# Cloud Resource Monitor

A cloud resource monitoring platform built using ASP.NET Core and PostgreSQL.

## Features
- Resource Management
- REST API
- PostgreSQL Database
- Swagger Documentation

## Technologies
- ASP.NET Core 8
- PostgreSQL
- Entity Framework Core
- Swagger
- GitHub

## API Endpoint

GET /api/Resources
